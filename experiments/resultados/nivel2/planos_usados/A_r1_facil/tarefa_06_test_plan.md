# Test Plan

1. Critério: A função `maior` deve retornar o maior número em uma lista que contém apenas números negativos.
   - entrada: maior([-3, -1, -4, -2])
   - esperado: -1
2. Critério: A função `maior` deve retornar o maior número em uma lista que contém números positivos e negativos.
   - entrada: maior([-5, 2, -3, 4, 1])
   - esperado: 4
